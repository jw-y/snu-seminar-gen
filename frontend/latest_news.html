SNU Data Science Seminar “Fast Code Sandboxes for AI Agents” Time : 09:00 - 10:30, Nov 18, 2026 Zoom: https://snu-ac-kr.zoom.us/j/2507466555 Abstract Al agents act via code. Given a task, the agent software calls a language model to plan what to do. The model outputs code (e.g., Python scripts). By executing that code, an agent can search the web, analyze data, or order a pizza. The execution result is fed back to the language model to produce the next action. By sending the code to a dedicated sandbox, agents can scale more easily. In this talk, I argue that existing sandboxes are poorly suited to AI agents: startup costs are high, and support for iteration is weak. In the first part, I introduce readie. It achieves extremely low-latency code execution through learned memory-state templates. Instead of loading a predefined disk image, readie memory-copies one of several provisioned templates, eliminating resource load time almost entirely. In the second part, I describe kishu. It makes iterative code revisions run much faster through incremental checkpoints. The key idea is a virtual page abstraction that saves dirty objects correctly and more efficiently. This talk will present these ideas through live demos and diagrams, with minimal text on slides. Yongjoo Park Yongjoo Park is an Assistant Professor in the Siebel School of Computing and Data Science at the University of Illinois Urbana-Champaign (UIUC). His research focuses on systems for data-intensive AI. He is a recipient of the NSF CAREER Award, the ACM SIGMOD 2025 Best Demo Award, and an Honorable Mention for the SIGMOD Jim Gray Doctoral Dissertation Award.
