SNU Data Science Seminar “Agentic AI: Define-Design-Build” Time : 09:00 - 10:30, Oct 28, 2026 Zoom: http: j/2507466555 Abstract Generative AI is moving from answering questions to completing tasks. Coding agents such as Claude Code, and now knowledge-work agents such as Claude Cowork, Microsoft Copilot Cowork, and OpenClaw, can read files, call tools, and deliver finished work across connected applications. Yet most people still use them as chatbots, and the gap between casual and frontier use keeps widening. This talk introduces Define-Design-Build, a practical method for turning an idea into a dependable agent through seven decisions: define the task and what success looks like; design the sources, skills, workflow pattern, and outputs with human- approval gates; and build through an iterative loop of prompt, run, refine, save as a skill, automate, and share. We explain the building blocks of today’s agents (tools, skills, the Model Context Protocol (MCP), subagents, and agent teams) and five patterns for splitting work: single pass, routine, pipeline, fan-out, and panel. Live demos include a parallel competitor-intelligence scan, a multi-agent pitch-deck review, and an annual-report-to- dashboard pipeline with a fully auditable trail. Finally, we trace the shift from vibe coding to agentic engineering and discuss why judgment, critical thinking, and communication matter more, not less, when agents do the work.
